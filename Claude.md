# Claude.md — superseded, see CLAUDE.md

This file was an earlier snapshot of the project's architecture reference —
written when the stack was a Python/LangGraph agent runtime on Ethereum
Sepolia, before the move to Base and the office/session/MCP-connector
architecture described in the current guide. `CLAUDE.md` (all-caps, repo
root) is the living reference now — it's also the exact filename Claude
Code itself looks for and auto-loads as project instructions, so keeping
two files both claiming to be "the" reference was actively misleading
rather than harmless duplication.

Nothing here is lost: `git log -- Claude.md` has the full prior content for
anyone who wants the historical snapshot. Read `CLAUDE.md` for anything
current.
